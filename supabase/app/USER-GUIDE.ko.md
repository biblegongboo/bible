# GongBoo Bible 사용자 안내서 (초안)

> Beta guide · 화면과 기능은 테스트 기간 동안 조금씩 다듬어질 수 있습니다.

GongBoo Bible은 성경 본문을 읽고, 장별 객관식 문제를 풀고, 인물·장소·사건을 서로 연결하여 살펴보는 학습 서비스입니다. 처음에는 **한 장을 읽고 → 문제를 풀고 → 궁금한 인물이나 장소를 따라가 보는 방식**이 가장 좋습니다.

## 1. 시작하기

1. 로그인 화면에서 이메일과 비밀번호를 입력합니다.
2. 학습할 성경 과목을 선택합니다.
3. **New Lesson**에서 책과 장을 고릅니다.
4. **Start**를 누르면 해당 장의 학습이 시작됩니다.
5. 이전에 하던 학습이 있으면 **Resume**에서 이어서 할 수 있습니다.

장 선택 목록의 숫자는 장 번호입니다. 장별 문제 수는 내부에서 자동으로 적용됩니다.

## 2. 상단 화면 읽기

맨 위 제목은 현재 학습 장을 짧게 표시합니다.

`Bib · Gen 14` = 창세기 14장

상단의 작은 버튼은 다음 기능을 엽니다.

| 표시 | 기능 |
|---|---|
| ▶ | 현재 문제 또는 본문 낭독 시작 |
| ↻ | 현재 항목 다시 듣기 |
| ■ | 낭독 중지 |
| `1.0×` | 낭독 속도 선택 |
| ⏭ | 자동 다음 항목 켜기/끄기 |
| 🌐 | Atlas: 장소·지도·여정·연대표·자료실 |
| 사람 아이콘 | People: 성경 인물 정보와 관계도 |
| ⎋ | 이 기기에서 로그아웃 |

버튼을 누르면 잠시 눌림과 파란 테두리 효과가 나타납니다. 한 번 누른 뒤 잠시 기다려 주세요.

## 3. 세 가지 학습 모드

| 모드 | 뜻 | 추천 상황 |
|---|---|---|
| **Lrn** | 정답과 해설을 바로 보며 학습 | 처음 읽는 장 |
| **Std** | 답을 고르면 즉시 정오답과 해설 확인 | 일반 복습 |
| **Exm** | 세트 제출 전까지 정답과 해설을 숨김 | 실력 확인 |

모드 이름 위에 마우스를 올리거나 휴대폰에서 길게 누르면 설명을 볼 수 있습니다. 시험 모드에서만 타이머가 표시됩니다.

## 4. 본문·퀴즈·언어 선택

### PSG

**PSG**를 켜면 현재 문제와 연결된 성경 본문을 표시합니다.

- Lrn: 본문이 기본으로 보입니다.
- Std: 필요할 때 본문을 보고 다시 문제를 풀 수 있습니다.
- Exm: 답을 제출하기 전에는 본문을 숨기는 방식으로 사용할 수 있습니다.

### Qz

**Qz**를 켜면 장별 객관식 문제를 함께 풉니다. 본문만 읽고 싶다면 Qz를 꺼도 됩니다.

### 언어

첫 번째 선택 칸은 주 본문 언어입니다. 예를 들어 `ModEng`는 현대 영어 WEB 본문입니다. 두 번째 칸은 함께 볼 두 번째 언어입니다. `None`은 두 번째 언어를 표시하지 않는다는 뜻입니다.

낭독도 화면에서 선택한 언어를 기준으로 합니다. 지원 음성은 사용하는 브라우저와 휴대폰에 설치된 언어 음성에 따라 다를 수 있습니다.

## 5. 문제 풀기

1. 본문과 문제를 읽습니다.
2. 네 선택지 중 하나를 누릅니다.
3. Std에서는 즉시 결과와 해설을 확인합니다.
4. 아래의 **Prev**, **Skip**, **Next**로 이동합니다.

본문 카드에 `Places in this passage`가 보이면, 그 절과 연결된 장소를 지도에서 볼 수 있습니다.

## 6. Atlas: 장소·지도·여정·연대표

상단 🌐 버튼을 누르면 Atlas가 열립니다.

| 탭 | 할 수 있는 일 |
|---|---|
| **Places** | 지명 검색, 설명, 좌표, 2.5D 벡터 지도 보기 |
| **Journeys** | 바울 등 정리된 이동 경로 보기 |
| **Timeline** | 성경 사건을 성경 순서로 살펴보기 |
| **Early Church** | 초기 교회 문헌 작품과 본문 읽기 |
| **Study** | 현재 구절과 관련된 주제·용어 보기 |
| **Library** | 단어, 사전, 주제, 책 소개 탐색 |

지도 조작 방법:

- 마우스 휠 또는 두 손가락 벌리기: 확대·축소
- 드래그: 지도 이동
- **Fit all**: 전체 범위로 되돌리기
- 지도 위 점·지명: 해당 장소 선택

장소, 사건, 인물 이름은 서로 연결되어 있습니다. 이름이나 칩을 누르면 관련 화면으로 이동합니다. Atlas 상단의 **← Back**, **Forward →**로 이전·다음 화면으로 돌아갈 수 있습니다.

## 7. People: 성경 인물 보기

상단 사람 아이콘을 누르면 People이 열립니다.

1. 검색 칸에 이름 또는 별칭을 입력합니다.
2. 첫 글자만 입력해도 해당 글자로 시작하는 목록이 나옵니다.
3. 인물을 선택하면 설명, 별칭, 성경 구절, 가족·관계, 관련 장소와 사건을 볼 수 있습니다.
4. 관계가 있는 인물은 가계도/관계도로 표시됩니다.
5. 관계가 없는 인물은 한 사람 카드로 정상 표시됩니다.

관계도는 성경 본문과 공개 데이터에서 제공한 연결을 시각화한 것입니다. 본문에 직접 명시되지 않은 논쟁적 해석을 확정 사실처럼 보이게 하지 않도록 주의합니다.

## 8. 관련 성경 구절에서 바로 학습하기

People, Atlas, Timeline 등에 보이는 `OT-Genesis-...`, `NT-Matthew-...` 같은 성경 구절 칩을 누르면 해당 장의 퀴즈 화면으로 돌아갑니다.

해당 절에 생성된 문제 중 가장 가까운 문제를 열어 줍니다. 아직 그 장의 문제가 생성되지 않은 경우에는 장만 열리거나 안내가 나타날 수 있습니다.

## 9. 낭독 사용 팁

- 처음에는 **1.0×** 속도를 권장합니다.
- 어려운 문장이나 문제는 **↻**로 다시 듣습니다.
- 자동으로 다음 문제까지 듣고 싶으면 **⏭**를 켭니다.
- 본문 낭독 뒤에는 생각할 시간을 두고 정답과 해설을 읽도록 설계되어 있습니다.
- 음성이 들리지 않으면 기기 볼륨, 브라우저의 미디어 권한, 설치된 한국어/영어 음성을 확인하세요.

## 10. 로그아웃과 안전

상단의 `⎋`를 누르고 확인하면 이 기기에서만 로그아웃됩니다. 다른 기기의 로그인이나 회원 정보는 바뀌지 않습니다.

공용 컴퓨터 또는 다른 사람의 휴대폰에서는 학습을 마친 뒤 반드시 로그아웃하세요.

## 11. 문제가 생길 때

| 증상 | 먼저 해 볼 일 |
|---|---|
| 화면이 이전 모양으로 보임 | 페이지 새로고침 또는 앱을 완전히 종료 후 다시 열기 |
| 문제 로딩이 늦음 | 잠시 기다린 뒤 한 번만 다시 시도 |
| 로그인 화면으로 돌아감 | 다시 로그인하고 올바른 성경 과목 선택 |
| 소리가 나지 않음 | 기기 음량과 브라우저/기기 TTS 설정 확인 |
| 지도·인물 창을 닫고 싶음 | 오른쪽 위 `×` 또는 **← Back** 사용 |

## 12. 베타 기간의 의견 보내기

오류를 발견하면 다음 네 가지를 함께 알려 주시면 가장 빨리 고칠 수 있습니다.

1. 사용한 기기와 브라우저 또는 앱 이름
2. 선택한 책·장 또는 인물·장소 이름
3. 어떤 버튼을 눌렀는지
4. 화면 사진 또는 오류 문구

---

이 서비스의 목표는 성경을 **본문 → 문제 → 인물 → 장소 → 사건 → 지도 → 여정 → 연대표**로 연결하여, 필요한 깊이만큼 스스로 탐색하며 공부할 수 있게 하는 것입니다.
